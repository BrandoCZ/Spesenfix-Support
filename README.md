# Spesenfix

Public pages for the Spesenfix iPhone and Mac app (travel expense reports for Germany): description, guide, calculation rules, privacy policy, FAQ, ideas and release notes. No app source code in this repository.

- Start: https://brandocz.github.io/Spesenfix-Support/ (German) and https://brandocz.github.io/Spesenfix-Support/en/ (English)
- Guide: [anleitung.html](https://brandocz.github.io/Spesenfix-Support/anleitung.html), [guide.html](https://brandocz.github.io/Spesenfix-Support/en/guide.html)
- Calculation: [berechnung.html](https://brandocz.github.io/Spesenfix-Support/berechnung.html), [calculation.html](https://brandocz.github.io/Spesenfix-Support/en/calculation.html)
- Privacy: [datenschutz.html](https://brandocz.github.io/Spesenfix-Support/datenschutz.html), [privacy.html](https://brandocz.github.io/Spesenfix-Support/en/privacy.html)
- Ideas and bugs: [open an issue](https://github.com/BrandoCZ/Spesenfix-Support/issues/new/choose) (please no real receipts, names or amounts)
