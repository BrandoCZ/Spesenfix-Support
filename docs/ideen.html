Ideen und Fehler melden

So geht es

  • Issue auf GitHub anlegen: Vorlagen für eine Idee und einen Fehler. Du brauchst ein GitHub-Konto.
  • Ohne GitHub: über die TestFlight-App („Feedback senden“) oder per E-Mail an mobile_bumbles_6z@icloud.com.
  • Bitte keine echten Belege, Namen, Beträge oder Zugangsdaten in öffentliche Issues. Beschreibe den Fall mit erfundenen Werten. Das Protokoll aus der App (Einstellungen › Diagnose) enthält keine solchen Daten; häng es gern an.

Ausblick (Ideen, keine Zusage)

  • Auslandsreisen mit Auslandssätzen und Fremdwährung
  • Mehrere Posten und Währungen je Beleg weiter ausbauen
  • Ansicht „So wurde gerechnet“ mit Rechenweg je Tag
  • Steuerelement im Kontrollzentrum und auf dem Sperrbildschirm zum Scannen
  • Automatisches Löschen auch im Hintergrund
  • Barrierefreiheit: vollständige Prüfung mit VoiceOver
